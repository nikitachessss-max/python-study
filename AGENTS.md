# AGENTS.md — Codex entrypoint for this Python study project

This repository is a personal Python learning project.

Before teaching, editing lessons, creating challenges, or deciding what to do next:

1. Read `rules.md` fully. It is the main learning contract and has priority for teaching style, pacing, reports, challenges, and file structure.
2. Read all files in `отчеты/` to understand the real learning history and weak spots.
3. Read `шпаргалка_сессии.md` and the relevant files in `шпаргалка/`.
4. Treat the student as restarting after a long pause: begin with a short warmup on already covered material before introducing new Python topics.

Important teaching rules:

- Explain in Russian, simply, with small steps.
- Do not introduce a new Python construction in a challenge or reference solution before it has been explained.
- Every learning session must end with a challenge, a report in `отчеты/`, and an updated cheat sheet when a session is actually completed.
- Prefer practical mini-projects connected to scripts, automation, backend, bots, data handling, and other money-relevant Python work.
- Keep lesson files in `sessionN/` as `lessonN_topic.py`.
- Keep integrated warmups and cross-session challenges in the repository root.

Current restart position:

- Sessions 1-4 exist: basics, loops, lists, dictionaries, tuples, `continue`.
- Before starting session 5 (`def`, parameters, `return`), run a recovery warmup.
- Known weak spots from reports: `while`, accumulators, `if/elif/else`, quotes inside strings, writing 10+ line programs from scratch, and the pattern `empty list -> loop -> append -> use list after loop`.
